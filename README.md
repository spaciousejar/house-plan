Two-storey house plans for a plot measured 32 x 28 x 32 x 41.5 ft (about 1,056 sq ft), with the 51.7 ft diagonal held exact. Road and main entrance on the East side. Ground floor 9 rooms, first floor 10, about 806 sq ft per floor.

- `index.html`: Sky House, the plan shaped by a reading / astronomy / workshop brief.
- `house-plan.html`: the base plan.
- `*.svg`: the site plan, both floors, and the front elevation as standalone drawings.

The plan uses a 4 ft 8 in cased opening instead of a door between the living room and the hall, on both floors. The front elevation is drawn to the same scale as the plans. Page four lists the modern spec: floor height, window size, roof, services, and finish.

Open either HTML file directly, or view the published copy at https://spaciousejar.github.io/house-plan/

Drawings are concept only. Have the plot re-surveyed and get the structural design from an engineer before construction.
